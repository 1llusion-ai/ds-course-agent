# 账号、邀请注册与统计管理台

管理入口为 `/admin`，使用与学生端相同的 Vue 3、Element Plus、Pinia、站内字体与图标，
共享浅色/深色主题。管理员与统计查看者登录后，可以从侧栏或设置页进入。

## 功能与权限

| 功能 | 学生 | 统计查看者 `observer` | 管理员 `admin` |
| --- | --- | --- | --- |
| 学生端及自己的学习记录 | 是 | 是 | 是 |
| 数据概览、课程汇总、CSV 导出 | 否 | 是 | 是 |
| 账号列表、个人使用汇总 | 否 | 否 | 是 |
| 创建账号、修改角色、停用恢复、重置密码、撤销登录 | 否 | 否 | 是 |
| 注册策略与邀请码管理 | 否 | 否 | 是 |
| 操作记录 | 否 | 否 | 是 |

账号列表可按关键词、角色、状态和注册日期过滤并分页。账号详情展示注册来源、最近登录、
最近学习、按课程的提问与练习提交量。用户名和学习身份不可通过管理接口更改。

本次范围不包括教材上传、资源发布、教师按课程授权、聊天正文查看、在线时长或模型费用统计。

## 初始化与迁移

所有运行数据继续保存在 `var/`，身份、邀请码、注册策略与操作记录存入 `AUTH_DB_PATH`。
新数据库默认关闭注册。数据库结构采用版本化迁移；已有用户默认是正常状态的学生，
注册来源为历史未知，旧学习身份与密码哈希保留。存在重复 `student_id` 时唯一索引迁移会失败，
需先确认这些账号的身份归属，不能自动合并历史学习数据。

给已有账号授予管理员权限：

```bash
.venv/bin/python scripts/admin.py bootstrap alice
.venv/bin/python scripts/admin.py bootstrap alice --confirm alice
```

第一条只显示计划，第二条才执行。用户名需要替换为实际账号；新安装可先沿用
`scripts/create_user.py` 创建本地账号，然后授予管理员权限。没有默认管理员凭据。
本地 bootstrap 同时可恢复被停用的管理员，操作会写入审计记录并撤销该账号的已有会话。

从旧版本升级时，发布前应备份 `var/auth.db`；保留原部署的环境变量，使用新代码显式迁移一次：

```bash
.venv/bin/python scripts/admin.py import-registration
.venv/bin/python scripts/admin.py import-registration --confirm import-registration
```

迁移命令读取旧 `.env` 中的 `AUTH_REGISTRATION_MODE`、`AUTH_INVITE_CODE`、
`AUTH_INVITE_EXPIRES_AT`、`AUTH_MAX_USERS`，进程环境变量优先。必须使用原部署的有效值；
旧 Compose 的隐式默认值（如 `invite`、容量 `60`）若没有写入 `.env`，迁移前需显式提供。
容器部署可在新镜像中使用 `python scripts/admin.py ...`，挂载同一份 `var/` 并注入原环境。
2026-11-08 已按用户授权完成线上迁移并将 `xiaofan422` 设置为唯一管理员；
详见 [管理台发布记录](admin_release_20261108.md)。

迁移保持原邀请码、有效期和全站容量；旧邀请码以校验摘要保存。历史注册来源不推测补齐，
迁移后的使用次数从新注册开始统计，历史账号仍占用全站容量。
管理员已经保存注册策略或已有邀请码时，重复导入会被拒绝。

运行服务不再读取这四个旧配置；后台数据库是注册策略的唯一权威来源。
未显式导入的升级实例保持注册关闭，已有账号仍可登录。迁移完成后删除旧环境变量即可。
旧会话令牌不包含账号 ID 和会话版本，因此升级后所有用户需要重新登录。
开发环境需要开放注册时，可通过显式迁移导入 `open`；生产环境始终拒绝 `open`，
管理页面只提供邀请注册与关闭注册。

## 邀请码与注册语义

- 邀请码由服务端随机生成，创建响应仅展示一次；数据库与日志不保存完整代码。
- 支持名称、备注、有效期、使用次数上限、停用恢复及分页使用记录。
- `max_uses=0` 表示不限；有效期为空表示长期有效；界面使用上海时间。
- 邀请码仅授予学生注册资格；不得指定角色或隐式赋予课程访问权限。
- 停用、过期和耗尽只影响后续注册，不影响已有账号。
- 账号创建、容量校验、邀请码计数和使用记录在一个 `BEGIN IMMEDIATE` 事务中完成。
  重复用户名等失败不占名额，并发注册不能突破额度。
- 全站容量按所有已创建账号计数，包括管理员与停用账号。管理端直接创建属于显式管理操作，
  不受自行注册开关和注册容量拦截，但会计入后续容量计算。停用账号不释放名额。

## 会话与操作记录

每次鉴权读取当前账号状态、角色和会话版本；停用、角色变更、重置密码和撤销登录会使旧会话
在后续请求失效，包含 SSE 重连。已经接受的后台生成任务不会因为账号调整而主动取消。
自己修改密码时仅为当前浏览器签发新 cookie，其他旧会话失效。
最后一名正常管理员不能被停用或降级；判断和更新在同一写事务中完成。

管理写操作再次在事务内检查管理员身份，并与成功操作记录一起提交。审计记录包含操作者、
操作、目标、时间和经过选择的变更前后字段。事务失败不会留下虚假的成功记录。
密码、令牌、邀请码完整内容和校验摘要不进入管理响应或审计记录。
管理响应禁用缓存；cookie 写请求校验浏览器 Origin，跨源部署必须正确设置 `CORS_ALLOW_ORIGINS`。

## 统计口径

日期采用 `Asia/Shanghai` 自然日，最大查询区间为 366 天。图表、明细和 CSV 共用同一统计函数。

- **账号**：全站当前账号数、角色与状态分布；新增账号按创建时间过滤，课程筛选不改变账号分母。
- **活跃用户**：周期内至少一次用户提问或练习提交，按学习身份去重；全站重新去重，不累加课程人数。
- **提问**：按学生、课程、会话、turn 去重；没有 turn ID 的历史消息使用消息 ID。
- **会话**：周期内创建且仍在存储中的会话。
- **练习发布量**：周期内分配的练习；**提交量**：周期内实际提交的练习，包括此前分配的练习。
- **完成率**：周期内发布的同一批练习，截至统计生成时已提交的比例；与期间提交量分开计算。
- **正确率**：周期内提交的练习中，正确作答题数除以已记录作答题数。没有分母时显示空值。
- **回答状态**：当前存储中 assistant 消息的 completed/stopped/error 分类，不声称覆盖所有 HTTP 请求失败。
- **注册来源**：周期内新注册账号按邀请码或来源分组；来源活跃为这些账号在同周期、所选课程内的活跃人数。

统计只读取保留记录，不读取聊天正文或答案内容；删除和未持久化的数据不能恢复。
历史账号的创建时间沿用原 SQLite UTC 语义；最近登录从升级后开始记录。
当前实现针对单机课程规模执行轻量事实查询和聚合，没有预聚合报表或长期访问日志。

## 所有权与验证

- `api/auth/` 拥有账号认证、角色、注册策略、邀请码与审计事务，调用 `shared/database.py` 的通用迁移设施。
- `api/session_statistics.py` 拥有会话存储的统计事实读取；`assessment/statistics.py` 拥有练习事实读取，
  返回类型化 dataclass，不向 API 反向依赖。
- `api/admin/` 负责管理 HTTP 适配和公开事实的报表组合，不直接读取领域数据库、不调用 agent 或模型。
- `web/src/views/admin/` 负责展示和交互；后端依赖统一校验权限，前端路由守卫只是体验约束。
- 原环境变量注册分支被删除；CLI 与接口共用同一个账号/注册所有者，仓库调用方已迁移到类型化用户。

对应测试：`tests/integration/api/test_admin_console.py`、`tests/test_admin_migration.py`、
`tests/test_admin_statistics.py`、原认证集成测试及 `web/tests/admin.spec.js`。
覆盖权限矩阵、会话撤销、最后管理员保护、跨源写拦截、失败事务回滚、并发注册额度、历史迁移、
跨课程与时区去重、练习统计分母、CSV 一致性及静态所有权边界。
