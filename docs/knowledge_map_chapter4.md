# 课程知识图谱与概念粒度

日期：2026-09-11。入口为聊天侧栏或学习画像中的「知识地图」，路径 `/knowledge-map`。

## KC 的边界

KC 是课程概念，层级为「章节 → 概念 KC」。OpenCV、DataFrame、缺失值处理、图像变换
都可以直接作为 KC。函数调用、参数设置和完成某个操作的步骤不构成图谱节点。

`data/knowledge_graph.json` 是问题映射和可视化的共同数据源，当前版本 1.6。
第 4 章补充表格数据读写、数据映射、数据排序、数据类型转换、训练集与测试集、
特征标准化、图像表示。第 10 章的「算法分析报告」和「答辩报告」属于竞赛交付物，
不作为 KC；它们保留为「数据科学竞赛流程」的检索别名。

第二轮复核进一步区分“可迁移的课程概念”和“教材用于说明概念的实例”。Anaconda、PyCharm
归入「Python 开发环境」；MNIST 手写数字识别归入 LeNet-5；美食图鉴项目归入卷积神经网络；
具体大语言模型产品归入「大语言模型」。三个助手案例合并为「大语言模型应用」，七个竞赛平台
合并为「数据科学竞赛平台」。原名称全部保留为归属概念的检索别名。课程最终包含 128 个 KC，
章节导航由 `data/目录.json` 生成。

2026-09-11 对十章 KC 进行了逐章人工复核。第一轮保留 canonical ID 并调整了
14 个不自然或容易误解的显示名称，例如「数据科学定义」改为「数据科学」、
「loc与iloc」改为「标签索引与位置索引」、「深度学习利器」改为「深度学习框架」。
旧显示名称保留为检索别名，不形成第二套节点。

关系也改为闭合的课程概念关系。`related_concepts` 只允许保存已存在的 canonical ID，且必须
双向声明；不再混入显示名称、工具名和无法解析的自由文本。两轮精修后，课程图包含
86 对相关关系、103 条带教学理由的先学关系和 16 对易混淆关系。加上 128 条章节归属关系后
共 333 条边。
每个 KC 至少有一条语义关系，关系端点全部存在，先学关系保持无环。
同一对 KC 只保留一种最明确的语义关系，避免“相关”与“先学/易混淆”形成重复连线。

37 项操作示例已归入对应概念的 `learning_points`，仅作为可选学习参考，既无独立概念 ID，
也不参与图谱连边、学习状态统计或 KC 数量计算。例如：

- 「从字典创建 DataFrame」属于 DataFrame 的学习参考。
- 「读取、显示与保存图像」属于 OpenCV 的学习参考。
- 「设置 Canny 的双阈值」属于边缘提取的学习参考。

明确操作名称和 API 名称作为所属概念的别名保留，用户提问这些操作时直接映射到概念。
概念之间的相关、先学和易混淆关系继续存在。没有通过隐藏节点来保留另一套操作级图谱。
调整前检查了本地 profiles 和 learning_events：没有这些已移除操作 ID 的历史记录；
现有学生文件未改写，也未引入 ID 兼容转发层。

## 模块契约

`teaching/knowledge_map.py` 负责类型化校验与个人状态投影；API 只适配 HTTP。
地图读取不初始化 AgentService、模型、embedding 或 Chroma。

- 节点类型只有 `chapter` 与 `kc`，KC 直接隶属章节。
- `LearningReference` 包含标题、目标、参考题及非空来源列表，属于节点内容，不是节点。
- `part_of` 从 KC 指向章节，根据归属生成。
- `prerequisite_of` 从建议先学的概念指向后续概念，103 条，全部附教学理由。
- `confusable_with` 为易混淆概念关系，16 对，无方向。
- `related_to` 来自节点间显式、对称的 canonical ID 引用，共 86 对，无方向。

包含关系和先学关系分别校验无环；节点 ID 唯一；所有关系端点存在。
先学关系表达教学建议，不把所有关系都声称为教材明确给出的必要先修条件。
旧自由文本关系已被清理，不再保留无法验证的关系或未解析计数。
原教学策略仍可消费相关概念的显示名称；本功能没有把学习路径规划替换成图搜索算法。
离线实验抽取器 `course_graph.py` / `build_course_graph.py` 不参与在线图谱加载。

## 交互与渲染

Vue 页面按需加载 `3d-force-graph` 与 Three.js。Cytoscape 及原二维矩形节点实现已替换。
默认展示全课程三维关系网络，按章节着色，支持旋转、缩放、聚焦、章节浏览、搜索、
局部关联视图、关系筛选及个人学习状态着色。布局使用真实关系和章节锚点；三维坐标
表达可视化布局，不宣称是高维 embedding 的语义投影。

概念节点只显示概念名；选中后打开简洁详情与关联概念，学习参考和教材出处默认折叠。
讲解/理解题按钮把概念级问题填入聊天输入框，由学生编辑后发送。
左侧知识点列表可用键盘操作；WebGL 不可用时仍保留列表和详情浏览。
小屏布局将详情放在画布下方。渲染依赖和字体均来自本地资产或浏览器系统字体。

Three.js 使用独立复制的节点与边数据，不允许力导向模拟修改 API 对象。
隐藏页面暂停动画；页面卸载销毁渲染器、观察器及自建纹理/材质。
默认静止浏览，用户可以开启旋转巡览；减少动态效果偏好会禁用镜头过渡。
