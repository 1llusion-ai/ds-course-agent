# 项目优化与问题清单

> 这份清单用于保存前期优化讨论的可追踪版本。最初的对话清单没有写入仓库，下面的内容根据现有提交、架构交接文档、测试结果和已经确认的运行状态重建。状态以代码和验证结果为准。

## 优先级说明

- **P0** 影响生产安全、数据隔离或核心可用性，应优先处理。
- **P1** 影响稳定性、可观测性、部署质量或主要教学流程，应在核心风险收口后处理。
- **P2** 影响性能、课程内容维护和管理效率，适合持续迭代。
- **P3** 研究性或产品扩展事项，先完成基线和评测再投入。

## 当前推荐顺序

1. 完成模型延迟可观测性，建立可比较的首 token、生成和重试数据。
2. 明确多进程配额和生产备份恢复周期。
3. 完成统一 CI 集成门禁，再处理前端拆包和课程内容质量指标。
4. 在数据和评测基线稳定后，再做学习者画像和多 Agent 扩展。
